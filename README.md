# Homebrew tap

```
brew install --cask dcvonb/tap/edgetodo
```

**EdgeTodo** is a todo panel for macOS that slides in from a screen edge, with two-way GitHub issue sync.
Requires macOS 14 or later. The app is signed with Developer ID and notarized by Apple.

Update with `brew upgrade --cask edgetodo`; remove with `brew uninstall --cask edgetodo` (`--zap` also removes its data).
